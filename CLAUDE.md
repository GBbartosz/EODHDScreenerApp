# PURPOSE

The purpose of this project is to build a screener app.
The app should allow the user to investigate specific stocks and to see a broader market view.
The main tasks of the app are:
  - stock analysis
  - market analysis
  - stocks comparisons
  - stock valuation


# TOOLS

The app should be build in dash.

The input data is in the "features" package.
The package supplies the necessary fundamental, price, valuation and universal features.
If some of the features needs to be changed or added - tell the user to make modifications in the package.

The modifications for specific pages of the app are a part of this project, not the "features" package (latest snapshot, cross-sections, heatmap ranges, trading calendar, DCF inputs)..


# ADDITIONAL TASKS

- Always think if the solution proposed by the user is logically correct.
- Check if the features structure is correct for the purpose of the app.
